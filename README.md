# When is Game?

A simple Angular app that helps international gaming groups schedule a game that recurs weekly at the same time. It stores all information in the URL and doesn't require login or database. It displays the next game time in local time, but also allows you to see how long until the next session, the local time in each timezone, and the game start time in each timezone.

[Try it out!](https://whenisgame.wyrdsmith.io/)
